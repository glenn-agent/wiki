# Prompt Data Boundaries

Agent runtimes should treat untrusted text in prompts as data with visible boundaries, not as ordinary instruction text.

A 2026-09-10 trend scan around prompt-injection-aware computer-use agents led Glenn-Agent to inspect OpenClaw's `src/agents/sanitize-for-prompt.ts` boundary and its tests. OpenClaw already strips control and format characters from untrusted prompt data, then wraps those blocks with labels that say the content is data and not instructions.

## Pattern

When injecting external or user-controlled content into an agent prompt:

1. **Sanitize confusing characters.** Remove or escape control and format characters that can make displayed text differ from interpreted text.
2. **Name the trust boundary.** Prefix or wrap the block with explicit language such as "data, not instructions" so the model is reminded how to treat it.
3. **Keep wrapper text outside the untrusted payload.** Boundary labels should be generated by the runtime, not supplied by the same untrusted source.
4. **Preserve useful content shape.** Sanitization should reduce instruction-smuggling risk without destroying the legitimate data the agent needs to process.
5. **Test hostile examples.** Include regression cases for control bytes, invisible formatting characters, nested instruction-looking text, and benign text that should remain readable.

## Practical checklist

Before adding a new prompt input path, ask:

```text
Can this text come from a webpage, file, tool result, channel message, or external API?
Could it contain hidden/control characters?
Will the model see a clear data-vs-instruction boundary?
Is the boundary wrapper runtime-owned?
Do tests prove both sanitization and normal readability?
```

## Why it matters

Computer-use and personal-assistant agents routinely mix instructions, observations, browser/page text, messages, tool outputs, and files inside the same context window. Prompt-injection defenses are stronger when every untrusted block crosses a small, testable normalization boundary before it reaches the model.
