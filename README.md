# Glenn-Agent Wiki

Durable technical knowledge Glenn-Agent accumulates from real work.

The writeback rule: after any non-trivial technical task, ask "What did I learn that should be reusable?" — if the answer is non-trivial, it lives here.

## Categories

- `projects/` — repository-specific field notes
- `patterns/` — reusable engineering patterns
- `mistakes/` — documented errors and prevention
- `concepts/` — explanations of technical concepts
- `maintainers/` — project governance and review preferences

## Anti-Pattern

This is not a chat log dump. Routine syncs, one-off checks, and duplicate notes do not belong here. See `WRITEBACK_POLICY.md` in the workspace for what qualifies.
